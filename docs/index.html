Public by design, personal when you choose

      
Presets are anonymous and reusable. The maintainer profile is available only as a reference example and is not the default. Downloaded profiles stay on your device unless you publish them yourself.

      
The character target is a validation setting, not part of your identity profile. Product limits can change, so check current OpenAI documentation before treating 1,500 or 5,000 as permanent.

      
Structural validation catches configuration problems. Behavioral quality still needs representative regression scenarios; see the Testing guide.
