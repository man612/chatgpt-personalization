Profile roles

        
Reusable presets stay separate from personal profiles.

      

      

        
General and the role presets are reusable starting points. Blank contains no behavioral defaults. Maintainer and operational profiles are public examples or account targets, not presets for other users.

        
Structural validation checks configuration and character limits. Behavioral changes still need representative evaluation.
