What changed in v2?

      
The old model treated personalization mostly as three text fields. v2 separates product controls from user context and response behavior, adds an explicit explanation contract for beginner-friendly depth, and removes answer length as a reason to force numbered sections.

      
The browser performs lightweight structural validation. The Python CLI adds secret-pattern, duplicate-text, prompt-bloat, output-limit, and outline-bias checks. Behavioral quality still requires regression testing against real prompts.
