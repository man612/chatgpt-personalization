Design boundary

        
Public by design, personal when you choose.

      

      

        
Presets are anonymous and reusable. The maintainer profile is a reference example, never the default. Downloaded profiles stay on your device unless you publish them yourself.

        
The character target is validation metadata, not identity. Structural validation catches configuration problems; behavioral quality still needs representative regression scenarios.
